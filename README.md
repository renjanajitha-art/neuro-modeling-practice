Small Python notebooks where I practice computational neuroscience: a spiking neuron and a learning agent.
# Neuro modeling practice

I am a zoology M.Sc. student learning computational neuroscience. This repository holds small notebooks I build to practise Python and modeling.

## Notebook 1: Neuron and learning agent

**Part 1: a simple neuron.**
A leaky integrate-and-fire neuron. I changed the input current and saw that spikes increase with current, and stop below a minimum current (the rheobase).

**Part 2: a learning agent.**
A simple Q-learning agent in a corridor of 7 boxes. It learns where the reward is. When I move the reward, the steps it needs go up, then come down again as it relearns.

## Tools
Python, NumPy, Matplotlib, Google Colab
